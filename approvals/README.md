# No approved tasks

There are no task authorization records, schemas that authorize a task,
execution tokens or dispatchers in this bootstrap. A source PR approval is not
an approved task record. Future records require a separately reviewed immutable
publication contract binding source, proposal digest, task/allowlist, runner,
TEST scope, lifetime/revocation and single-use identity. Fail closed until then.

Publication/expiry/revocation/single-use semantics are now proposed in
[the review contract](../docs/TASK_APPROVAL_PUBLICATION_V1.md). This remains a
design document: no approved task, operational ledger or dispatcher exists.
